## 2. API Architecture & Transport Principles

1. **Single Entry Point (`doPost(e)`):**
   All API requests are sent via HTTP POST to the deployed Google Apps Script Web App URL.
2. **Text/Plain POST Transport:**
   To prevent browser CORS preflight (`OPTIONS`) requests—which Apps Script Web Apps cannot handle—the client sends requests with header `'Content-Type': 'text/plain;charset=utf-8'` and JSON stringified body.
3. **HTTP 302 Redirect Handling:**
   Apps Script redirects successful requests to `script.googleusercontent.com`. The frontend `apiClient.ts` uses `redirect: 'follow'`.
4. **Server-Side Authorization:**
   Protected operations require verified HMAC-SHA256 session tokens. Unauthorized requests return `{ ok: false, error: { code: 'UNAUTHORIZED' } }`.
5. **Transient Identifiers vs Physical Columns:**
   Physical Google Sheets tables have no `package_id`, `payment_id`, or `session_id` columns. Transient identifiers generated by API handlers or clients are mapped back to student IDs, row indices, or composite keys on the server.

## 3. Request & Response Envelopes

### 3.1 Standard Request Envelope
```json
{
  "apiVersion": "1",
  "operation": "students.list",
  "identityToken": "eyJhbGciOiJIUzI1NiJ9...signature",
  "requestId": "req_1730000000000_abc123",
  "idempotencyKey": "idemp_optional_uuid",
  "payload": { ... }
}
```

### 3.2 Standard Response Envelope
```json
{
  "apiVersion": "1",
  "requestId": "req_1730000000000_abc123",
  "ok": true,
  "data": { ... },
  "error": null,
  "meta": {
    "totalCount": 26,
    "timestamp": "2026-11-17T12:00:00.000Z"
  }
}
```

### 3.3 Error Envelope
```json
{
  "apiVersion": "1",
  "requestId": "req_1730000000000_abc123",
  "ok": false,
  "data": null,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Student name is required",
    "details": { "student_name": "Required field" },
    "retryable": false
  }
}
```

## 4. Authoritative Operation Registry

### 4.1 System & Authentication

#### `system.health`
- **Description:** Verifies Web App responsiveness and health.
- **Access:** Public.
- **Payload:** `{}`.
- **Returns:** `{ status: "ok", apiVersion: "1", schemaVersion: "2.0.0", checkedAt: ISOString }`.

#### `auth.verifySession`
- **Description:** Validates administrator session token and returns identity.
- **Access:** Protected.
- **Payload:** `{}`.
- **Returns:** `{ authenticated: true, displayIdentity: string, actorId: string, verifiedAt: ISOString }`.

---

### 4.2 Students Domain

#### `students.list`
- **Description:** Lists all student records from `Students` sheet.
- **Payload:** `{ query?: string, status?: string }`.
- **Returns:** Array of `Student` objects (`student_id, student_name, parent_name, parent_phone, parent_email, student_phone, student_email, subject, status, primary_meeting_link`).

#### `students.get`
- **Description:** Retrieves a single student by ID.
- **Payload:** `{ student_id: string }`.
- **Returns:** `Student` object.

#### `students.create`
- **Description:** Appends a new student to `Students` (10 columns). Generates next sequential `student_id` (`STU_xxx`).
- **Payload:** `{ student_name: string, parent_name: string, parent_phone: string, parent_email?: string, student_phone?: string, student_email?: string, subject?: string, status?: string, primary_meeting_link?: string }`.
- **Returns:** Created `Student` object.

#### `students.update`
- **Description:** Updates existing student record matched by `student_id`.
- **Payload:** `{ student_id: string, updates: Partial<Student> }` (supports `primary_meeting_link`).
- **Returns:** Updated `Student` object.

#### `students.archive` / `students.reactivate`
- **Description:** Sets student status to `ARCHIVED` or `ACTIVE`.
- **Payload:** `{ student_id: string }`.
- **Returns:** Updated `Student` object.

---

### 4.3 Packages & Renewal Domain

#### `packages.list`
- **Description:** Lists packages from `Packages` sheet (12 columns), enriched with dynamically calculated consumed and remaining classes.
- **Payload:** `{ student_id?: string }`.
- **Returns:** Array of `Package` objects.

#### `packages.get` / `packages.getBalance`
- **Description:** Retrieves a student's package and aggregate balance breakdown across all packages.
- **Payload:** `{ student_id: string }` or `{ package_id?: string }`.
- **Returns:** Enriched package object (`classes_purchased, consumed_classes, remaining_classes, is_exhausted`).

#### `packages.create`
- **Description:** Creates a package record in `Packages` (12 columns).
- **Payload:** `{ student_id: string, student_name?: string, plan_type: string, currency?: string, package_price: number, per_class?: number, classes_purchased: number, class_duration?: number, class_schedule?: string, start_date?: string, end_date?: string, next_due_date?: string }`.
- **Returns:** Enriched `Package` record.

#### `packages.update`
- **Description:** Updates a package row in `Packages` matched by `student_id` (or `_rowIndex`).
- **Payload:** `{ student_id: string, updates: Partial<Package> }`.
- **Returns:** Updated `Package` record.

#### `packages.renew` / `students.renew`
- **Description:** Executes package renewal workflow under shared ScriptLock (`RenewalService.Packages_renew`). Appends a new package row, preserves historical row, optionally records payment, and schedules future classes.
- **Payload:**
  ```json
  {
    "student_id": "STU_001",
    "classes_purchased": 12,
    "package_price": 6000,
    "currency": "INR",
    "plan_type": "PACKAGE",
    "class_duration": 60,
    "start_date": "2026-11-20",
    "class_schedule": "Mon - 6:00 PM, Wed - 6:00 PM",
    "schedules": [
      { "day_of_week": "Monday", "start_time": "18:00", "end_time": "19:00" }
    ],
    "first_class_date": "2026-11-20",
    "payment": {
      "amount": 6000,
      "payment_date": "2026-11-20",
      "currency": "INR",
      "in_inr": 6000
    },
    "idempotency_key": "idemp_ren_..."
  }
  ```
- **Returns:** `{ success: true, data: { package: Package, payment?: Payment, scheduled_count: number } }`.
- **Errors:** `AMBIGUOUS_RENEWAL_RECOVERY` if recovery cannot unambiguously prove state.

---

### 4.4 Schedules Domain

#### `schedules.list`
- **Description:** Lists recurring schedule entries for a student parsed from `Packages.class_schedule`.
- **Payload:** `{ student_id: string }`.
- **Returns:** Array of `WeeklyScheduleEntry` objects.

#### `schedules.save`
- **Description:** Persists updated recurring weekly schedule string to `Packages.class_schedule` holding shared ScriptLock (`LockManager.withLock`).
- **Payload:** `{ student_id: string, schedules: WeeklyScheduleEntry[] }`.
- **Returns:** `{ success: true, data: WeeklyScheduleEntry[] }`.

---

### 4.5 Payments Domain

#### `payments.list`
- **Description:** Lists payment records from `Payments` sheet (6 columns).
- **Payload:** `{ student_id?: string, startDate?: string, endDate?: string }`.
- **Returns:** Array of `Payment` records (`student_id, student_name, payment_date, amount, currency, in_inr`).

#### `payments.record`
- **Description:** Appends a payment record to `Payments`. Supports `idempotency_key` caching.
- **Payload:** `{ student_id: string, student_name?: string, payment_date: string, amount: number, currency: string, in_inr?: number, idempotency_key?: string }`.
- **Returns:** Created `Payment` record.

#### `payments.void`
- **Description:** Physically deletes the matching payment row from the `Payments` sheet and records a durable tombstone in `ScriptProperties` (`payment_void_<id>`).
- **Payload:** `{ payment_id?: string, student_id?: string, amount?: number, payment_date?: string, void_reason?: string }`.
- **Returns:** `{ success: true, data: { payment_id: string, status: "VOID", void_reason: string } }`.
- **Errors:** `AMBIGUOUS_RECORD` if multiple identical rows exist; `RECORD_NOT_FOUND` if no matching row is found.

---

### 4.6 Class Sessions Domain

#### `classes.list`
- **Description:** Lists sessions from `ClassSessions` sheet (9 columns) with derived end-times and durations from `Packages`.
- **Payload:** `{ student_id?: string, startDate?: string, endDate?: string }`.
- **Returns:** Array of `ClassSession` objects (`student_id, student_name, schedule_date, schedule_time, duration_minutes, attendance_status, session_status, deduct_class, cancellation_reason, session_notes`).

#### `classes.schedule` / `classes.create`
- **Description:** Schedules a single class session with overlap conflict detection.
- **Payload:** `{ student_id: string, student_name?: string, schedule_date: string, schedule_time: string, duration_minutes?: number }`.
- **Returns:** Scheduled session record.

#### `classes.batchSchedule`
- **Description:** Inserts multiple class sessions idempotently under a script lock.
- **Payload:** `{ student_id: string, sessions: Array<{ schedule_date: string, schedule_time: string, duration_minutes?: number }> }`.
- **Returns:** `{ count: number, data: ClassSession[] }`.

#### `classes.complete` / `classes.recordAttendance`
- **Description:** Marks session completed with attendance outcome and deductions.
- **Payload:** `{ class_session_id?: string, session_id?: string, _rowIndex?: number, student_id: string, attendance_status: string, deduct_class?: boolean, session_notes?: string }`.
- **Returns:** Updated `ClassSession` record.

#### `classes.cancel`
- **Description:** Cancels a class session. User must provide `cancellation_reason`. Preserves `session_notes`. If $\ge 4$h notice or waived, auto-schedules a replacement session.
- **Payload:** `{ class_session_id?: string, session_id?: string, _rowIndex?: number, cancellation_reason: string, credit_waiver?: boolean, session_notes?: string }`.
- **Returns:** Updated `ClassSession` record and optional `replacement_session`.

#### `classes.restoreCredit`
- **Description:** Restores credit on an erroneously deducted session in-place (`deduct_class = false`).
- **Payload:** `{ class_session_id?: string, session_id?: string, _rowIndex?: number }`.
- **Returns:** Updated `ClassSession` record.

---

### 4.7 Reports & Dashboard Domain

#### `dashboard.overview`
- **Description:** Returns aggregate metrics (active students, upcoming classes, total outstanding balance).
- **Payload:** `{}`.
- **Returns:** Dashboard metrics object.

#### `reports.financialSummary`
- **Description:** Returns financial breakdown grouped strictly by currency (total payable, total paid, net outstanding, available credit).
- **Payload:** `{ currency?: string }`.
- **Returns:** Currency financial metrics object.
